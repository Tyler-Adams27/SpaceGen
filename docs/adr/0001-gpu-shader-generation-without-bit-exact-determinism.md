# GPU shader generation without bit-exact determinism

Skyboxes are generated by GPU shaders evaluated per cubemap face, so the Preview updates live and the Export reuses the same shaders at higher resolution. The same Seed and settings give the same look, but floating-point results can differ slightly between GPUs and drivers, so bit-exact reproduction is not promised. The exported images, not the Project, are the source of truth.

## Considered Options

- **CPU generation**: can be bit-reproducible, but cannot drive a live Preview at useful resolutions and makes Preview and Export diverge.
- **GPU shaders (chosen)**: real-time editing and "what you see is what you export", at the cost of cross-machine bit-exactness.

## Consequences

- Regenerating a Project on another machine may differ in tiny pixel values.
- Anyone needing identical skyboxes in a repo must commit the exported images.
